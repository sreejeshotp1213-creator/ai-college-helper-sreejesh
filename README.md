🎓 College Helper

A simple student-focused web application designed to help college students access useful college information quickly.

🚀 Features

- 🎤 Voice input
- 📚 College-related information
- 💰 Fee information
- 📊 Attendance information
- 📱 Mobile-friendly interface
- 🤖 AI-assisted functionality

🛠️ Technologies

- HTML
- CSS
- JavaScript
- Google AI Studio
- GitHub

🎯 Purpose

College Helper is a BCA-level project created to learn real-world software development, GitHub, and AI-assisted development.
